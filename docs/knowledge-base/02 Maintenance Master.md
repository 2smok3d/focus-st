# 02 · Maintenance Master

> Ford minimum + FFST conservative schedule for an 86k turbo car in AZ heat. Full version → [Google Doc](https://docs.google.com/document/d/101vmqJBHxNubTItKtKKMdRedJH6z2rEv6DaTXOjFI0Q). Working log → [[MAINTENANCE]].

## Immediate reset (unless a dated receipt proves it)
Oil+filter · full module scan + battery test · brake/clutch fluid · coolant condition · spark plugs · tires/brakes · MMT6 fluid · air+cabin filters · EVAP/purge + VIN campaign · charge-air leak · alignment.

## Cadence
- **Every fuel stop** (until consumption known): oil/coolant level, leaks.
- **Monthly:** tires, fluids, lights, charge-pipe, scan.
- **5,000 mi / 6 mo:** oil+filter, rotate, brakes, suspension — **3–4k if tuned / AZ heat**.
- **10,000 mi:** plugs if tuned, PCV, exhaust, charge-air clamps, battery pre-summer.
