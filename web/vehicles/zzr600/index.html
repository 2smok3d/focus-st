Systems Status

Fuel / Carbs
Assume varnished after a sit — clean/rebuild 4× CVK, then bench + vacuum sync.
Charging
Era regulator/rectifier is a known weak point. Confirm 14.0–14.5V @ RPM before trusting it.
Fuel delivery
Vacuum petcock diaphragm + cracked intake boots cause flooding / lean hunting.
Brakes
35-yr rubber lines swell → mushy lever. Flush DOT 4; consider braided lines.
Suspension
Fork seals likely weeping; refresh fork oil. Check steering-head + linkage bearings.
Final drive
Inspect 525 chain stretch + sprocket hooking; replace as a set if worn.

05

Diagnosis

This bike is carbureted and pre-OBD-II — there is no ECU and no fault codes, so the garage's Code Lookup doesn't apply here. Diagnosis is analog: compression + leakdown, carburetor vacuum sync, spark + coil checks, charging-voltage tests, and fuel-delivery inspection (petcock, float levels, intake boots). Log findings the same way — a symptom, the test that proved it, and the fix — even without a scan tool.
