Systems Status

two-stroke priorities
Crank seals
Seize risk. 40-yr seals harden → air leak → lean → seizure. Pressure-test the crankcase before any hard running.
Powervalve (YPVS)
Carbons up + servo/cables stick. Decarbon and verify a full open/close sweep.
Oil supply (Autolube)
Never run the injection tank dry. Verify pump operation + throttle-cable sync before start.
Fueling / jetting
Carbs varnish after a sit. If de-catted or on chambers, it MUST be rejetted — read plug color.
Cooling
Liquid-cooled — flush coolant, inspect hoses + water-pump seal.
Chassis
Fork seals, steering-head + swingarm bearings, brake lines, tire date codes.

Recommission Checklist

before first start
Crankcase pressure/vacuum test
Prove the crank seals hold before running — a lean air leak seizes a two-stroke.
Fill + verify the Autolube oil tank & pump

Drain old fuel · clean carbs · set jetting

05

Diagnosis

This is a carbureted two-stroke — no ECU, no fault codes, so the garage's Code Lookup doesn't apply. Diagnosis is analog and two-stroke-specific: crankcase pressure test (air leaks → lean seize — the number-one killer), cylinder compression, spark plug color reads for jetting, ignition/CDI checks, and powervalve operation. When in doubt, jet rich and read the plugs — a lean two-stroke is a seized two-stroke.
