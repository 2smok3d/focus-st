Engine Decision

open
Fresh 22R-EDirect fit — keeps the EFI + W56, simplest wiring. The reliable, period-correct path (~$1.8k).
3RZ-FE 2.7LMore torque, still a Toyota four — needs mounts, wiring, and ECU work (~$2.5k).
5VZ-FE 3.4L V6Biggest power jump — the largest fab, cooling, and wiring job of the three (~$3k+).
Recommendation: unless a V6 is the goal, a clean 22R-E keeps the build simple and keeps the truck's character — decide this first, since it drives the harness, mounts, cooling, and cluster choices downstream.

Diagnosis

The 22R-E is OBD-I, not OBD-II — so the garage's Code Lookup (OBD-II P-codes) doesn't apply. This truck reports faults as flash codes: with the ignition on, jumper the diagnostic check-connector terminals (T/TE1 to E1) and count the Check-Engine-Light blinks — e.g. a slow even flash is "system normal," and grouped blinks map to a two-digit code (RPM signal, O2 sensor, etc.). Read those against the factory manual for this engine. Otherwise it's classic mechanical diagnosis: compression, fuel pressure, spark, timing.
